## 5. Бенчмарк

Для каждого варианта все три таблицы Bronze скопированы в bench, затем выполнен полный Q16 по этим копиям. Данные, масштаб, колонки и SQL одинаковы. Запись — один прогон с суммарным временем трёх CTAS; чтение — один прогрев и пять измеряемых прогонов в переменном порядке. Внешнее время включает запуск CLI и получение результата. Это тёплый локальный эксперимент, не официальный TPC-H benchmark.

| Формат | Кодек | Размер трёх таблиц, MiB | Запись, с | Q16 медиана, с | Q16 min–max, с | Вывод |

| PARQUET | ZSTD | | | | | |
| ORC | GZIP | | | | | |

При полном прогоне добавить NONE и SNAPPY для обоих форматов. Приложить times.csv, writes.csv, summary.csv и размеры. Слабую разницу не интерпретировать как устойчивое преимущество.
